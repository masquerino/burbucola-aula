Burbucola es una entidad ficticia creada para una actividad académica. No debe utilizarse para recopilar datos personales reales innecesarios.

La versión incluida permite identificar a los alumnos mediante el nombre introducido y almacenar sus respuestas en una base de datos local. Para uso real en una institución educativa, adapta el sistema a las políticas de privacidad, seguridad y protección de datos de tu universidad.
